## 1. Контекст

### 1.1. Задача

Компания занимается монтажом наружной рекламы. Расчёт стоимости плёнки сейчас делается вручную менеджером — долго, с ошибками, зависит от квалификации.

### 1.2. Решение

Веб-калькулятор, который принимает параметры объекта и возвращает предварительную стоимость монтажа и демонтажа плёнки.

### 1.3. Пользователи

- **Клиент** — вводит параметры, получает оценку.
- **Менеджер** — использует для быстрой оценки при звонке.

### 1.4. Границы

**Входит:**
- Плёнка на стекло и не-стекло.
- Монтаж, демонтаж, выезд.
- Минимальная стоимость заказа.

**Не входит:**
- Баннеры, вывески, лайтбоксы — отдельные спецификации.
- ПВХ/ПЭТ на двусторонний скотч — отдельный тип изделия.
- Крепёж — для плёнки не применяется.
- Форма заявки с загрузкой фото — отдельная задача.

## 2. Сценарии использования

### UC-01: Расчёт для стекла, старая плёнка нормальная

**Предусловие:** клиент знает площадь и состояние старой плёнки.  
**Основной поток:**
1. Выбирает поверхность → «Стекло».
2. Вводит площадь → 15 м².
3. Выбирает состояние → «Нормальная».
4. Нажимает «Рассчитать».
5. Видит итоговую стоимость и пометку «предварительно».

### UC-02: Расчёт для не-стекла, старая плёнка неровная

**Предусловие:** клиент знает площадь, состояние и ровность старой плёнки.  
**Основной поток:**
1. Выбирает поверхность → «Не-стекло».
2. Вводит площадь → 8 м².
3. Выбирает состояние → «Старая».
4. Появляется поле «Ровность» → выбирает «Нет».
5. Нажимает «Рассчитать».
6. Видит сообщение о том, что этот случай — другой тип изделия, и ссылку.

### UC-03: Клиент не знает состояние плёнки

**Предусловие:** клиент знает только площадь и поверхность.  
**Основной поток:**
1. Выбирает поверхность.
2. Вводит площадь.
3. Выбирает состояние → «Не знаю».
4. Нажимает «Рассчитать».
5. Видит **вилку** — от минимальной до максимальной стоимости.

## 3. Входные параметры

| ID | Поле | Тип | Значения | Обяз. | Условие показа |
|---|---|---|---|---|---|
| IN-01 | Поверхность | radio | Стекло / Не-стекло | Да | Всегда |
| IN-02 | Площадь | number | > 0, м² | Да | Всегда |
| IN-03 | Состояние старой плёнки | radio | Нет / Нормальная / Старая / Не знаю | Да | Всегда |
| IN-04 | Ровность старой плёнки | radio | Да / Нет / Не знаю | Да | Только если IN-01 = Не-стекло И IN-03 = Старая |

**Примечание к IN-04:** для стекла не спрашиваем — там всегда снимаем, ровность не влияет на сценарий.

## 5. Спецификация расчёта

### 5.1. Ставка монтажа (PLACEHOLDER)

Убывающая по площади.

| Площадь, м² | Ставка, ₽/м² |
|---|---|
| 0–10 | 600 |
| 10–20 | 500 |
| 20–30 | 400 |
| 30+ | 300 |

**PLACEHOLDER:** границы и значения — заглушка. Заменить на реальные.

### 5.2. Формулы

**Монтаж:**
```
M = ставка(площадь) × площадь
```

**Демонтаж:**
```
D = ставка(площадь) × коэффициент_демонтажа × площадь
```

| Сценарий | Коэффициент |
|---|---|
| Нормальная (стекло / не-стекло) | 0.70 |
| Старая (только стекло) | 1.50 |
| Нет старой / блекаут поверх | 0 |

**Сумма работ:**
```
S1 = M + D
```

**Выезд (интерполяция):**
```
если S1 ≤ 5000:          V = 1500
если 5000 < S1 < 10000:  V = 1500 × (10000 − S1) / 5000
если S1 ≥ 10000:         V = 0
```

Свойства функции:
- Монотонная — рост S1 не уменьшает V.
- Непрерывная — нет скачков на границах.
- Без арбитража — клиент не может «сэкономить», добавив 1 ₽ к заказу.

**Итог до округления:**
```
Raw = max(M + D + V, 3000)
```

**Итог после округления:**
```
Total = округление(Raw, до 100 ₽)
```

Направление округления — см. OQ-02.

### 5.3. Таблица решений

| № | Поверхность | Состояние | Ровность | Действие | Коэф. демонтажа |
|---|---|---|---|---|---|
| 1 | Стекло | Нет | — | Монтаж на чистую | 0 |
| 2 | Стекло | Нормальная | — | Снять полосами, убрать 20–30% клея, монтаж | 0.70 |
| 3 | Стекло | Старая | — | Скребок/куски, убрать ~100% клея, монтаж | 1.50 |
| 4 | Стекло | Не знаю | — | Вилка | 0.70–1.50 |
| 5 | Не-стекло | Нет | — | Монтаж на чистую | 0 |
| 6 | Не-стекло | Нормальная | — | Снять целой частью, клей не убираем, монтаж на старый клей | 0.70 |
| 7 | Не-стекло | Старая | Да | Блекаут поверх (не снимаем) | 0 |
| 8 | Не-стекло | Старая | Нет | ПВХ/ПЭТ на скотч → редирект | — |
| 9 | Не-стекло | Старая | Не знаю | Вилка | 0–0.70 |
| 10 | Не-стекло | Не знаю | — | Вилка | 0–0.70 |

### 5.4. Формат вывода

**Обычный сценарий:** одна цифра, например `6 800 ₽`.

**Вилка:** две цифры, например `от 4 700 ₽ до 10 200 ₽`.

**Пометка под результатом (всегда):**
> Стоимость предварительная. Точная — после фото или осмотра. Приложите фото в форме заявки.

## 6. Обработка краевых случаев

### 6.1. Невалидный ввод

| Случай | Поведение |
|---|---|
| Площадь = 0 | Ошибка «Площадь должна быть больше 0» |
| Площадь < 0 | Ошибка «Площадь должна быть больше 0» |
| Площадь не число | Ошибка «Введите число» |
| Поле пустое | Кнопка «Рассчитать» неактивна |
| Не выбрана поверхность | Кнопка «Рассчитать» неактивна |
| Не выбрано состояние | Кнопка «Рассчитать» неактивна |

### 6.2. Границы ступеней ставки

На границах 10, 20, 30 м² — значение попадает в **верхнюю** ступень.  
Пример: 10 м² → ставка 500 ₽/м² (не 600).

**PLACEHOLDER:** правило принадлежности границы — уточнить (OQ-01).

### 6.3. Границы выезда

На границах 5 000 и 10 000 ₽ функция непрерывна, разрывов нет.

### 6.4. Минимальная стоимость

Если `M + D + V < 3000` → итог 3000 ₽.  
Если `M + D + V ≥ 3000` → итог не меняется.

При срабатывании минималки под результатом дополнительно выводится:
> Минимальный заказ 3 000 ₽. Можно обсудить индивидуально.
