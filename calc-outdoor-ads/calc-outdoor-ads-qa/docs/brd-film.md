**Метод:** аналитика требований, чёрный ящик (для будущего тестирования)

---

## 1. Назначение

Калькулятор рассчитывает **предварительную** стоимость монтажа и демонтажа плёнки на объекте.

Клиент вводит параметры — получает цифру или вилку. Финальная стоимость — после фото или осмотра.

**Что решает:**
- Снимает с менеджера рутинные расчёты.
- Даёт клиенту понимание цены до звонка.
- Отсекает неадекватные запросы (минималка 3 000 ₽).

**Чего не делает:**
- Не считает баннеры, вывески, ПВХ/ПЭТ на скотч (отдельные BRD).
- Не учитывает крепёж (плёнка клеится).
- Не заменяет выезд.

## 2. Входные параметры

| № | Поле | Тип | Значения | Обяз. | Условие показа |
|---|---|---|---|---|---|
| 1 | Поверхность | radio | Стекло / Не-стекло | Да | Всегда |
| 2 | Площадь | number | > 0, м² | Да | Всегда |
| 3 | Состояние старой плёнки | radio | Нет / Нормальная / Старая / Не знаю | Да | Всегда |
| 4 | Ровность старой плёнки | radio | Да / Нет / Не знаю | Да | Только если `Поверхность = Не-стекло` И `Состояние = Старая` |

**Пояснение по полю 4:** для стекла не спрашиваем — там всегда снимаем. Для не-стекла спрашиваем, потому что от ровности зависит сценарий.

## 4. Формулы расчёта

### 4.1. Базовая ставка монтажа (PLACEHOLDER)

Убывающая по площади.

| Площадь, м² | Ставка, ₽/м² |
|---|---|
| 0–10 | 600 |
| 10–20 | 500 |
| 20–30 | 400 |
| 30+ | 300 |

**PLACEHOLDER:** границы и значения — заглушка. Заменить на реальные.

### 4.2. Монтаж

```
M = ставка(площадь) × площадь
```

### 4.3. Демонтаж

```
D = ставка(площадь) × коэффициент_демонтажа × площадь
```

| Сценарий | Коэффициент |
|---|---|
| Нормальная (стекло / не-стекло) | 0.70 |
| Старая (только стекло) | 1.50 |
| Нет старой / блекаут поверх | 0 |

### 4.4. Выезд (интерполяция)

```
S1 = M + D

если S1 ≤ 5000:          V = 1500
если 5000 < S1 < 10000:  V = 1500 × (10000 − S1) / 5000
если S1 ≥ 10000:         V = 0
```

**Свойства:** монотонная, без арбитража, непрерывная. Дробные значения — норма.

### 4.5. Итог

```
Итог = max(M + D + V, 3000)
```

**Минималка 3 000 ₽.** Если меньше — поднимаем. Приписка в UI: «Минимальный заказ 3 000 ₽. Можно обсудить индивидуально.»

### 4.6. Округление

До 100 ₽. Направление — **ОТКРЫТЫЙ ВОПРОС** (вверх / по математике).

## 6. Формат вывода

**Обычный сценарий:** одна цифра.

**Вилка:** «от X до Y».

**Всегда:** приписка «Стоимость предварительная. Точная — после фото или осмотра. Приложите фото в форме заявки.»

---

## 7. Что НЕ входит

- ПВХ/ПЭТ на скотч — отдельный BRD.
- Баннер — отдельный BRD.
- Вывески, лайтбоксы, объёмные буквы — отдельный BRD.
- Крепёж — для плёнки не применяется.
- Форма заявки с фото — отдельная задача.
